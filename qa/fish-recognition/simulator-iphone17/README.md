# iPhone 17 실제 앱 어종 판별 확인

검사일: 2026-09-10 (KST). iPhone 17 / iOS 26.3, 시뮬레이터 `26276C0D-16DA-4780-82E0-0FFC837228E6`.
사용 중인 iPhone 17 Pro와 별도로 실행했다. 이 앱 전용 Metro 8083을 사용했다.

실제 앱에서 임시 계정으로 로그인 → 사진 보관함 선택 → 운영 판별 응답 → 결과 화면을 확인했다. 카메라 권한 및 사진 보관함 전체 접근 없이 선택한 사진으로 분석했다. 어종 최종 확정이나 조과 저장은 하지 않았다.

| 입력 | 앱 표시 결과 | 소요 시간 |
|---|---|---|
| 조피볼락으로 라벨된 사진 | 쏨뱅이 → 개볼락 → 조피볼락 | 21.243초 |
| 넙치로 라벨된 사진 | 문치가자미 → 도다리 → 참가자미. 넙치는 후보에 없음 | 21.506초 |
| 모래 위 발자국 사진 | 후보 없음, 비어류임을 설명하고 재촬영 안내 | 5.998초 |
| 심하게 픽셀화된 물고기 사진 | 후보 없음, 세부 특징 부족을 설명하고 재촬영 안내 | 6.465초 |

시간은 로컬 사진 보존부터 최종 분석 상태 업데이트까지이며 순수 모델 응답 시간은 아니다. 각 JSON에 입력 경로, 후보, 상태와 시간이 있고, PNG에 실제 결과 화면을 보존했다.

## 판단

사진 선택부터 실제 AI 응답 표시까지 작동했다. 비어류 및 저화질 사례에서는 어종 후보를 강제로 만들지 않고 재촬영을 안내했다. 실제 물고기 두 장에서는 기존 라벨과 첫 후보가 달랐고, 넙치 사례에서는 기존 라벨이 상위 3개에도 없었다. 후보 순위와 가자미류 구분은 추가 개선 및 검증이 필요하다.

두 어류 사진의 기존 라벨은 전문가가 확정하지 않았으므로 이 결과를 확정 오답이나 정확도 수치로 사용하지 않는다. 네 사례만 확인했으며 카메라 실촬영, 실기기 성능, 전체 어종 정확도 검증을 대체하지 않는다. 재촬영 설명문 안에는 추정 어종 문구가 남을 수 있다(저화질 사례의 농어 언급).

## 정리 상태

임시 계정은 통계 집계 제외 설정으로 검사했고 로그아웃 후 로그인 화면을 확인했다. 임시 계정 영구 삭제는 자동 승인 검토에서 명시적 삭제 승인 부족으로 거절되어 보류 중이다. 계정 비밀번호는 이 결과물에 포함하지 않았다.


후속 상태: 사용자가 임시 계정 보존을 요청하여 삭제하지 않았다. 후속 개선 시험은 [개선 시험 보고서](../input-model-comparison/improvement-trial-report.md)에 기록했다.
