# 사용자 사진·판별 결과 저장 확인

확인일: 2026-09-10. 앱 소스, 운영 DB 컬럼·집계·트리거·Storage 버킷 설정을 읽기 전용으로 확인했다. 사용자 사진을 내려받거나 별도 학습 자료로 복사하지 않았고, 수집 범위를 변경하지 않았다.

## 결론

운영하면서 사용자가 저장한 조과 사진과 어종 선택은 축적된다. 그러나 실패·재촬영 사례까지 포함한 개선용 자료 수집은 준비되지 않았다. 기존 저장 자료는 사용자 선택 기록이며, 전문가가 확정한 정답이 아니다.

| 항목 | 현재 동작 | 제한 |
|---|---|---|
| 조과 사진 | 최종 저장 시 비공개 user-uploads에 업로드 | 카메라 원본 그대로가 아니라 기본 긴 변 최대 1280px, JPEG 품질 0.75로 최적화한 사진이다. 원본 화질 전체가 보존된다고 보면 안 된다. |
| AI 후보 | user_catches.candidate_fish_ids에 후보 ID 배열 저장 | 배열 순서는 앱 후보 순서를 따른다. 점수·이유·모델/프롬프트 버전은 서버에 저장하지 않는다. |
| 최종 어종 선택 | fish_id 또는 custom_species_name 저장. id_method로 후보 선택/직접 검색 구분 | 사용자 선택은 독립 정답이 아니다. |
| 저장 후 어종 수정 | 최초 선택·수정 시각과 private.catch_species_changes 이력 저장 구조 및 트리거 있음 | 현재 수정 사례가 0건이라 이번 확인에서는 실제 수정 이력을 관찰하지 못했다. |
| 실패·재촬영 | 실패/거절 이벤트를 사진 없이 통계에 전송하도록 구현 | 사진과 개별 분석 시도를 잇는 ID가 없다. 재촬영 버튼 누름 자체의 별도 이벤트도 없다. 이벤트 전달은 best-effort다. |
| 저장하지 않은 사진 | 기기 임시 큐에 존재할 수 있음. 재촬영 시 해당 큐·파일 제거 | 운영 서버의 사진 자료로 남지 않는다. 현재 고지와 일치한다. |
| AI 점수·이유 | 기기 임시 큐의 candidates에 존재 | 저장 성공 후 큐가 제거된다. needs_retake와 note는 큐 필드에도 별도 보존되지 않는다. |
| 동의 | 사진을 외부 AI로 보내 후보를 받는 안내와 기기 내 accepted 값 | 사진을 개선·학습용으로 따로 제공하는 선택 및 사용자별 서버 동의 이력은 확인되지 않았다. 기존 동의를 별도 학습 활용 동의로 간주하지 않는다. |
| 인증 표시 | 위치·시각 등 조과 기록 조건을 검증 | field_verified/metadata_verified는 생물학적 어종 정답 확인이 아니다. |

## 운영 DB 확인값

- 전체 조과 31건, 사진 경로 또는 URL 참조 26건, 후보 배열이 비어 있지 않은 조과 12건, 어종 선택 31건.
- 어종 수정 표시 0건, 수정 이력 0건. 보호·수정 이력 트리거 활성화 확인.
- user-uploads 버킷 public=false.
- 최근 30일 관련 이벤트: ai_analysis_started 1건, ai_analysis_succeeded 1건. 조회한 실패·거절·최종 선택 이벤트는 없음.
- 이 집계는 테스트·과거 기록을 구분하지 않은 값이다. 실제 사용자 수, 정답 데이터 수 또는 오류율로 해석하지 않는다. 사진 참조가 있는 것은 실제 객체 다운로드 성공을 뜻하지 않는다.
- QA 계정의 analytics_excluded 설정과 이벤트 전송 실패 가능성이 있어 이벤트 0건을 해당 행동이 없었다는 증거로 쓰지 않는다.

## 다음 보완 범위

1. 저장한 조과에 AI 후보별 점수·이유, 모델/판별 규칙 버전, 분석 시도 ID를 함께 연결한다. 최초 AI 출력은 수정 이력과 분리해 보존한다.
2. 사진 제공은 AI 기능 사용과 분리된 선택으로 설계한다. 무엇을 제공하는지, 실패 사진 포함 여부, 보관 기간과 철회·삭제 동작을 정한 뒤 안내와 동의 기록을 함께 구현한다. 제공하지 않아도 일반 판별·기록 기능은 사용할 수 있도록 한다.
3. 동의한 사진만 개선 검토 목록에 넣고, 기본 라벨은 user_selected/unreviewed로 둔다. 현장 인증을 정답 검수로 바꾸지 않는다.
4. 실패 사례를 수집한다면 분석 시도 단위로 원인·사진·재촬영·최종 선택을 연결한다. 전체 카메라 원본을 무조건 보관하기보다 식별에 필요한 화질과 보관 범위를 먼저 정한다.

현재는 **기존 운영을 통해 저장된 조과가 쌓이는 단계**다. 자동 학습이나 검증 자료 수집이 완성된 상태는 아니다. 이번 작업은 저장 현황 확인이며 신규 수집·동의 화면의 구현이나 배포는 하지 않았다.
