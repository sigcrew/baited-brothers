# 사용자 흐름 점검 — 2026-09-10

대상: 최신 로컬 앱, iPhone 17 / iOS 26.3, 기존 QA 계정. iPhone 17 Pro와 다른 프로젝트 서버는 변경하지 않았다. 수정본은 앱 스토어 배포 전이다.

## 발견 및 수정

1. **업데이트 후 미완료 사진 복구 실패**: iOS 데이터 컨테이너 경로가 바뀌어 이전 URI로 사진을 찾지 못했다. 실제 사진 7개는 새 Documents 폴더에 남아 있었다. 큐를 읽을 때 현재 Documents 기준으로 경로를 복원한다. 회귀 검사 실패→통과 및 실제 기존 사진 복원·저장 확인.
2. **촬영 화면 오류 안내 가려짐**: 존재하지 않는 기록을 열면 루트 팝업이 전체 화면 촬영 화면 뒤에 가려졌다. 촬영 화면 내부에 안내 제공자를 배치했다. 같은 오류 상황에서 팝업 확인과 홈 복귀 성공.
3. **위치 거절 시 지도 수동 선택 차단**: 직접 누른 지도 좌표에도 기기 위치 권한을 요구했다. 수동 선택은 권한 없이 진행하고 지명 조회 실패 시 기본 이름을 쓴다. 현재 위치 버튼만 권한을 요구한다. 동일 좌표로 거절 상태에서 선택·즐겨찾기·출조 생성 성공.
4. **물때 날짜 혼동**: 08:28은 실제 서버 데이터상 다음 날이었다. 주요 만조·간조 표시에는 ‘내일’을 붙이고 다음 물때 선택에서 지난 시각을 제외한다. 지도 화면 및 회귀 검사 2개 확인.
5. **앱 내부 개인정보 안내 누락**: 공개 웹과 달리 앱에는 이전 시행일과 내용이 남아 있었다. 사진 선택 제공·90일·철회 안내와 2026.09.10 시행일을 동일하게 반영했다.

추가로 Jest가 Deno 전용 이미지 테스트를 실행하던 설정을 수정했다. 제외한 검사는 Deno에서 별도 실행하여 모두 통과했다.
