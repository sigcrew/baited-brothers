# 로그인 상태 QA (2026-10-21)

iPhone 16 Pro 시뮬레이터(iOS 26.3, Debug 빌드, 사용자 본인 계정 로그인)로 홈 → 일지 → 출조 상세 → 조과 기록(사진 보관함 → AI 판별 → 저장 → 완료) → 지도(해양 정보) → 수집(도감·배지·카드) → 프로필 → 프로필 수정·알림 설정까지 실제로 눌러 봤다. 기록 흐름은 실제 Anthropic 호출과 Supabase 저장을 거쳤고, 도다리 사진을 1순위로 정확히 판별해 출조에 연결된 조과가 저장됐다.

전날 반영한 UX 변경(온보딩, 게스트 정리, 도감 힌트, 빈 상태, 라벨, 완료 CTA)은 모두 로그인 상태에서도 의도대로 보였다.

## 처리 기록

- 2026-10-21: 5·6·7·9·11번 처리. 후보·선택 카드 학명을 이명법만, 판별 개선 참여 카드를 어종 선택 아래로, 저장 버튼을 "도다리로 기록하기"(조사 자동), 알림 설정 문구를 사용자 말로, 카드 "SIZE N/R"을 "크기 미기록"으로.
- 2026-10-21: 3번 처리. `summarizeCollectionCoverage()`로 인증 조과와 일반 기록을 따로 세어, 프로필 통계와 도감 상단에 "위치가 확인된 조과만 반영 · 일반 기록 N건은 카드에만" 안내를 넣고, 일반 기록으로만 잡은 어종의 잠긴 카드에 "일반 기록만 있음 · 위치 인증 시 발견" 표시.
- 2026-10-21: 2번 처리. 배지 모달 프레임 아래에 이름·설명·획득 조건·진행도(예: 0 / 1 완료 출조)와 "탭하거나 좌우로 밀면 뒷면" 안내 추가, 시트 최대 높이를 화면의 88%로.
- 2026-10-21: 1·4번 처리. `src/lib/tripSchedule.ts`(tripCountdown/pickNextTrip)로 홈 "다음 출조"는 오늘 이후 출조를 우선하고, 전부 지났으면 가장 최근 것을 "정리할 출조"로 D+N과 "완료로 표시" 버튼과 함께 보여 준다. 일지 카드는 지난 예정 출조에 "예정일 지남" 라벨.

## 정상 확인된 것

- 사진 보관함 → AI 판별 → 어종 확정 → 저장 → 완료 → 출조 상세에 조과 표시까지 끝까지 동작. 판별 정확(도다리 1순위).
- 지도 장소 시트의 해양 정보(KMA 예보, 시간대별 날씨, 바람) 로드. 즐겨찾기·출조 마커·필터 칩 집계.
- 프로필 "SINCE 2026.07", 카드 3장, 프로필 수정·알림 설정 화면.
- 완료 화면 주 CTA "대천항 출조로 돌아가기" 동작.

## 추천 처리 순서

1. **1·4번 묶음**: 지난 예정 출조 처리. D-day를 "지난 출조 · D+40"으로 바꾸고, 홈 "다음 출조"는 오늘 이후 출조만 고르며, 지난 예정 출조에는 "완료로 표시" 버튼을 일지 카드와 홈에 노출.
2. **2번**: 배지 모달을 `BottomSheetScrollView`로 바꾸거나 최대 높이를 화면 비율로.
3. **3번**: 프로필 통계와 도감 상단에 "인증 조과만 반영 · 일반 기록 N건" 한 줄. 도감 카드에 "일반 기록으로 N회 잡음" 표시도 고려.
4. **5·6·7·9·11번**: 문구·순서 정리 한 커밋.
5. **8번**: 출조 연결 조과를 출조 장소 집계에 포함.

10번은 실기기에서 확인한 뒤 판단.
