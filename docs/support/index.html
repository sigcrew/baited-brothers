자주 묻는 질문

위치 권한 없이 조과를 기록할 수 있나요?

네. 촬영 전 안내에서 ‘위치 없이 계속’을 선택하면 사진 분석과 일반 조과 저장을 계속할 수 있습니다. 해당 기록은 위치 미인증 상태로 저장되어 지도 표시와 도감 해금에서는 제외됩니다.

사진 보관함의 사진도 인증할 수 있나요?

네. 선택한 사진에 촬영 위치와 시각이 있고 해당 위치가 연안으로 확인되면 도감·배지·개인 최대어에 반영됩니다. 사진 위치가 없거나 확인되지 않으면 일반 기록으로 저장됩니다. 사진 보관함 기록은 위치 메타데이터를 수정할 수 있어 랭킹에서는 제외됩니다.

AI가 물고기 어종을 자동으로 확정하나요?

아닙니다. AI는 최대 3개의 후보를 제안하며, 사용자가 최종 어종을 직접 선택해야 기록됩니다. 후보가 맞지 않으면 도감에서 직접 검색할 수 있습니다.

조과 사진을 사진 앱에 저장하려면 어떻게 하나요?

일지에서 완료한 출조를 열고 현장 기록의 조과 카드에서 ‘사진 저장’을 누르세요. 사용자가 선택한 사진을 추가할 때만 사진 추가 권한을 요청합니다.

계정을 삭제하려면 어떻게 하나요?

앱의 프로필 → 계정 → 계정 탈퇴에서 계정과 연결된 출조·조과·사진을 삭제할 수 있습니다.
