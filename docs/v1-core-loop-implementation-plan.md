# v1 핵심 수집 루프 구현 계획

기준일: 2026-07-30

## 목표

첫 출시에서는 기능 확장보다 아래 핵심 루프가 실제 현장에서 반복되는지
검증한다.

```text
첫 조과 저장
  → 새 어종 도감 해금
  → 다른 출조에서 두 번째 새 어종 해금
```

활성화는 첫 새 어종 해금이며, 핵심 리텐션은 첫 해금과 다른 출조에서
60일 안에 새 어종을 다시 해금한 경우다. 출조가 없는 기록은 첫 해금과
최소 24시간 간격이 있어야 재방문으로 본다.

## 구현 순서

### P0. 현장 조과 증거 유실 방지

1. 셔터 직후 최적화한 사진을 앱 문서 디렉터리에 복사한다.
2. 사진 경로, 촬영 시각, GPS, 위치 정확도, 출조 ID와 멱등 키를 로컬 큐에
   저장한다.
3. 앱 종료·재실행 후에도 미완료 작업을 복구한다.
4. 온라인 복구 또는 앱 포그라운드 진입 시 AI 판별과 저장을 재시도한다.
5. 사용자가 직접 재시도하거나 미완료 작업을 삭제할 수 있게 한다.
6. 서버 저장 성공을 확인한 뒤에만 로컬 사진을 삭제한다.
7. 로그아웃·계정 전환 시 다른 사용자의 작업을 업로드하지 않는다.

#### P0 인수 기준

- 비행기 모드에서 촬영한 사진과 위치가 앱 문서 디렉터리에 남는다.
- 촬영 직후 앱을 강제 종료해도 다음 실행에서 작업이 보인다.
- 네트워크 복구 후 AI 후보 선택 단계로 이어갈 수 있다.
- 어종 확정 뒤 업로드가 실패해도 입력과 사진이 유지된다.
- 동일 작업을 반복 저장해도 `client_request_id`로 조과가 한 건만 생성된다.
- 저장 완료 전에는 로컬 원본을 삭제하지 않는다.
- 로컬 보존 실패 시 성공처럼 표시하지 않고 촬영 화면에 오류를 보여준다.

### P1. 데이터·서버

- 사용자당 24시간 AI 판별 30회 안전 한도
- 어종 변경 이력과 도감 보상 재계산
- FIELD 60 밖 일반 기록용 데이터 모델
- 수정된 어종의 `사용자 정정` 출처 구분
- 첫 해금과 다른 출조의 60일 리텐션 집계
- 신규 테이블·함수 RLS 및 역할별 권한 검증

### P2. 핵심 화면

- 첫 발견 완료 화면: `도감 보기`를 주 CTA로 사용
- 재포획 완료 화면: `카드 보기`를 주 CTA로 사용
- 출조 연결 기록: `한 마리 더 기록하기` 제공
- 후보 목록: 감수된 식별 특징과 유사종 차이를 표시
- FIELD 60 식별 데이터를 앱 번들에도 포함
- AI 동의 거부 시 `AI 없이 기록하기` 제공
- FIELD 60 밖 `도감에 없는 어종` 일반 기록 제공
- 설정에 개인정보 최소화 문제 신고 진입점 제공

### P3. 출시 검증

- 비어류·저품질 거부율 95% 이상
- Top-3 90%는 출시 차단 조건이 아닌 장기 개선 목표
- AI가 20초를 넘으면 직접 검색을 제공하되 분석은 최대 60초까지 유지
- 실제 연안 낚시 사용자 20~30명 현장 베타
- 최소 100명 활성화 코호트의 60일 관찰 후 리텐션 판단
- 다른 출조의 두 번째 새 어종 해금률 35% 이상을 초기 성공 가설로 사용

## v1에서 제외

- 시즌 챌린지, 스트릭, 랭킹
- 광고, 구독, 시즌 패스, 유료 스킨
- 외부 조과 카드 공유
- 친구 비교, 피드, 커뮤니티
- 완전한 오프라인 지도와 최신 해양 정보 보장

## 제품 불변 조건

- 로그인은 앱 사용 전에 필요하며 현재 로그인 화면 순서를 유지한다.
- 하단의 홈·일지·지도·수집·프로필 구조를 유지한다.
- 기록 진입점은 홈·수집·어종 상세의 현재 위치를 유지한다.
- 위치 실패는 일반 기록으로 저장하되 인증 도감에는 반영하지 않는다.
- AI는 후보만 제시하고 어종을 자동 확정하지 않는다.
- AI 동의와 관계없이 직접 선택으로 기록할 수 있다.
- 지도·날씨·물때 장애는 조과 기록과 도감에 전파되지 않아야 한다.
