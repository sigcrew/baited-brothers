## Android 확인 메모

- 범용 Debug APK는 213MB로 기존 AVD의 설치 여유 공간이 부족했다.
  Pixel 9에 맞춘 arm64 Debug APK(72MB)는 기존 앱 데이터를 보존한 채
  정상 설치됐다.
- Android 15의 상태 표시줄·내비게이션 바와 홈 고정 CTA, 하단 탭,
  지도, 수집, 카드 상세 화면에서 잘림이나 중첩은 발견되지 않았다.
- 개발 모드의 Reanimated `reduced motion` 경고만 발생했으며 앱 오류나
  크래시는 아니었다.
- 로그인 화면에서 키보드를 열면 제출 버튼이 가려지고 화면을 위로
  스와이프해도 이동하지 않는다. 키보드를 닫으면 제출할 수 있어 차단
  오류는 아니지만 Android 키보드 회피 UX 개선 항목으로 남긴다.
- 저장된 인증 세션이 만료된 상태였으므로 Android에서 동의 → 촬영 →
  후보 비교 → 확정의 인증 후 전체 흐름은 이번 실행에서 재검증하지 못했다.

## 출시 전 실제 기기에서 확인할 항목

아래 항목은 카메라, 앱 강제 종료, 실제 네트워크 전환 또는 배포된 서버가
필요하므로 시뮬레이터 정적 확인만으로 완료 처리하지 않는다.

1. Android 실제 기기에서 카메라·사진 선택·위치 권한과 키보드 회피 확인
2. 비행기 모드에서 촬영 직후 앱 강제 종료
3. 재실행 후 홈의 `미완료 현장 기록`에서 사진·GPS·출조 연결 복구
4. 네트워크 복구 후 AI 후보 단계까지 자동 재시도
5. 어종 확정 후 업로드 실패와 앱 강제 종료
6. 재실행 후 선택 어종·크기·메모 복구 및 동일 멱등 키 재사용
7. 서버 성공 전 로컬 사진이 남고, 성공 후에만 삭제되는지 확인
8. 로그아웃·다른 계정 로그인 시 이전 사용자의 큐가 업로드되지 않는지 확인
9. AI 30회 한도에서 31번째 요청은 차단되고 직접 선택은 유지되는지 확인
10. 도감 밖 어종이 일반 카드에는 남고 도감·배지·랭킹에는 반영되지 않는지 확인
11. 어종 정정 이력 생성, `사용자 정정` 표시, 랭킹 제외 확인

## 베타와 지표

- 실제 연안 낚시 사용자 20~30명으로 현장 베타를 수행한다.
- 비어류·저품질 사진 거부율 95% 이상을 출시 차단 기준으로 본다.
- Top-3 90%는 장기 개선 목표이며 이번 출시 차단 기준이 아니다.
- 활성화 사용자 100명 이상이면서 각 사용자의 60일 관찰이 끝난 코호트만
  리텐션 판단에 사용한다.
- 초기 성공 가설은 다른 출조에서 두 번째 새 어종을 해금한 비율 35% 이상이다.
